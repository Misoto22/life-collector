# Life Collector - 个人生活收藏夹

English | [中文版本](README.zh-CN.md)

Life Collector 是一个现代化的个人收藏管理 Web 应用，帮助你记录和分享生活中的美好时刻。

## 🌟 主要功能

### 收藏管理
- 餐厅收藏：记录你喜爱的餐厅，包括位置、特色菜品、评分等信息
- 电影收藏：保存你看过的精彩电影，添加个人评价和观后感
- 旅行目的地：记录你想去的地方，添加旅行计划和期待

### 用户体验
- 响应式设计：完美支持手机端和桌面端
- 卡片式布局：直观展示所有收藏内容
- 个性化界面：自定义主题和布局

### 社交功能
- 用户认证：安全的登录和注册系统
- 内容分享：与朋友分享你的收藏

## 🛠️ 技术栈

- 全栈框架：Next.js 14 (App Router)
- 前端：React.js + TypeScript
- UI 框架：Tailwind CSS
- 数据库：Neon (PostgreSQL)
- 认证：Firebase Authentication
- 部署：Vercel
