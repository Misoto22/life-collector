# Life Collector - Personal Collection Hub

[中文](#chinese) | English

Life Collector is a modern web application for managing personal collections, helping you record and share beautiful moments in life.

## 🌟 Key Features

### Collection Management
- Restaurant Collection: Record your favorite restaurants, including location, signature dishes, and ratings
- Movie Collection: Save your favorite movies with personal reviews and thoughts
- Travel Destinations: Keep track of places you want to visit, add travel plans and expectations

### User Experience
- Responsive Design: Perfect support for both mobile and desktop
- Card Layout: Intuitive display of all collections
- Personalized Interface: Customizable themes and layouts

### Social Features
- User Authentication: Secure login and registration system
- Content Sharing: Share your collections with friends

## 🛠️ Tech Stack

- Full-stack Framework: Next.js 14 (App Router)
- Frontend: React.js + TypeScript
- UI Framework: Tailwind CSS
- Database: Neon (PostgreSQL)
- Authentication: Firebase Authentication
- Deployment: Vercel

# Life Collector - 个人生活收藏夹

[English](#readme) | 中文

Life Collector 是一个现代化的个人收藏管理 Web 应用，帮助你记录和分享生活中的美好时刻。

## 🌟 主要功能

### 收藏管理
- 餐厅收藏：记录你喜爱的餐厅，包括位置、特色菜品、评分等信息
- 电影收藏：保存你看过的精彩电影，添加个人评价和观后感
- 旅行目的地：记录你想去的地方，添加旅行计划和期待

### 用户体验
- 响应式设计：完美支持手机端和桌面端
- 卡片式布局：直观展示所有收藏内容
- 个性化界面：自定义主题和布局

### 社交功能
- 用户认证：安全的登录和注册系统
- 内容分享：与朋友分享你的收藏
